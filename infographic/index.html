Classical supervised learning.

Learns from examples that already carry the right answer. The output is a number (regression) or a category (classification).

Linear regression

SupervisedRegression

Tabular data

Fits the straight line that minimizes the squared gap to every point.

  • Price forecasting
  • Delivery time estimates
  • Demand projection
More

How it works. Fits a straight line (or a flat plane in many dimensions) through the training points by choosing the weight for each feature that minimizes the squared gap between predicted and actual values.

Used for. Forecasting house prices from size and location, estimating delivery time from distance and load, projecting monthly demand.

Logistic regression

SupervisedClassification

Tabular dataNatural language

Squashes a weighted sum through an S-curve to get a probability, then thresholds it.

  • Credit scoring
  • Spam filtering
  • Churn prediction
More

How it works. Takes a weighted sum of the features and squashes it through an S-shaped curve so the result is a probability between 0 and 1, then applies a threshold to assign a class.

Used for. Credit default and loan approval scoring, spam filtering, customer churn prediction, baseline sentiment classifiers on bag-of-words text.

Naive Bayes

SupervisedClassification

Natural languageTabular data

Multiplies how likely each feature is under each class and picks the most probable class.

  • Spam and phishing filters
  • Email routing
  • Sentiment baselines
More

How it works. Applies Bayes' theorem while assuming each feature is independent of the others given the class: it multiplies how likely each feature value is under each class and picks the class with the highest combined probability.

Used for. Spam and phishing filters, routing support emails by topic, quick sentiment baselines, symptom-based triage where features are counts or yes-or-no flags.

Decision tree

SupervisedClassification, regression

Tabular data

Asks yes-or-no questions one feature at a time, each chosen to make the groups purest.

  • Readable loan rules
  • Medical triage
  • Produce sorting
More

How it works. Asks a sequence of yes-or-no questions about one feature at a time, choosing each question so the resulting groups are as pure as possible (Gini impurity or entropy), until each leaf holds mostly one class.

Used for. Loan approval rules that a reviewer can read, medical triage checklists, sorting produce by measured size, color, and shape.

Random forest

SupervisedClassification, regression

Tabular data

Hundreds of trees grown on random samples of rows and features vote on the answer.

  • Fraud detection
  • Churn prediction
  • Feature importance
More

How it works. Trains hundreds of decision trees, each on a random sample of rows and a random subset of features, and lets them vote. Averaging many imperfect trees cancels out the overfitting of any single one.

Used for. Fraud detection on transaction records, churn prediction, ranking which features matter most in a dataset.

Gradient boosting (XGBoost, LightGBM)

SupervisedClassification, regression

Tabular data

Small trees built in sequence, each one fitted to the errors the earlier ones left.

  • Click prediction
  • Risk pricing
  • Tabular competitions
More

How it works. Builds small trees one after another; each new tree is fitted to the errors the ensemble is still making, so the model improves in the direction of steepest error reduction.

Used for. Click-through and conversion prediction, insurance risk pricing, the most common winner of tabular data competitions.

Support vector machine

SupervisedClassification

Tabular dataNatural language

Finds the boundary with the widest margin between classes; kernels let it curve.

  • Text categorization
  • Digit recognition
  • Bioinformatics
More

How it works. Finds the boundary between classes that leaves the widest possible margin to the nearest training points. Kernel functions let the same idea draw curved boundaries.

Used for. Text categorization with TF-IDF features, handwritten digit recognition, protein classification in bioinformatics.

K-nearest neighbors

SupervisedClassification, regression

Tabular dataComputer vision

Finds the k closest stored examples and takes their majority label.

  • Similar-item recommendations
  • Anomaly detection
  • Small image baselines
More

How it works. Keeps the whole training set. To classify a new item it measures the distance to every stored item, takes the k closest, and returns their majority label (or their average for regression).

Used for. Similar-item recommendations, anomaly detection in sensor readings, quick baselines for small image datasets.

Classical unsupervised learning.

Works on unlabeled data and finds structure in it: groups, directions of variation, outliers.

K-means clustering

UnsupervisedClustering

Tabular dataComputer vision

Assigns points to the nearest of k centers, moves each center to the mean, repeats.

  • Customer segmentation
  • Color quantization
  • Ticket grouping
More

How it works. Places k center points, assigns every item to its nearest center, moves each center to the average of its members, and repeats until the assignments stop changing.

Used for. Customer segmentation for marketing, reducing an image to a palette of k colors, grouping similar support tickets or documents.

Principal component analysis

UnsupervisedDimensionality reduction

Tabular dataComputer vision

Projects the data onto the few directions along which it varies most.

  • Feature compression
  • 2D visualization
  • Noise reduction
More

How it works. Finds the directions along which the data varies the most and projects every item onto the top few, so dozens of correlated features collapse into a handful of uncorrelated ones.

Used for. Compressing features before training another model, plotting high-dimensional data in two dimensions, removing noise from measurements, the classic eigenfaces approach to face recognition.

Hierarchical clustering

UnsupervisedClustering

Tabular data

Merges the two closest clusters again and again, building a tree you can cut at any height.

  • Customer taxonomies
  • Gene expression groups
  • Nested topics
More

How it works. Starts with every item as its own cluster and repeatedly merges the two closest clusters. The result is a tree (dendrogram) that can be cut at any height to get as many groups as wanted.

Used for. Building a customer or product taxonomy, grouping genes by expression pattern, organizing a document collection into nested topics.

DBSCAN

UnsupervisedClustering, anomaly detection

Tabular data

Grows clusters out of dense regions and leaves sparse points as noise.

  • Transaction anomalies
  • Geographic hotspots
  • Unknown cluster counts
More

How it works. Grows clusters out of dense regions: any point with enough neighbors within a set radius becomes a core point, its neighbors join the cluster, and points in sparse regions are left unassigned as noise.

Used for. Flagging anomalous transactions, finding geographic hotspots in GPS or delivery data, clustering without having to choose the number of groups in advance.

Deep learning.

Neural networks with many layers that learn their own features from raw pixels, tokens, or audio. These power computer vision, language models, and generative AI.

Convolutional neural network

SupervisedClassification, detection

Computer vision

Slides learned filters across the image, building edges into textures into objects.

  • Image classification
  • Object detection
  • Medical imaging
More

How it works. Slides small learned filters across the image. Early layers respond to edges and colors, middle layers to textures and parts, and late layers to whole objects, so the network builds its own visual features.

Used for. Image classification, object detection for self-driving perception, tumor detection in medical scans, defect inspection on production lines.

Transformer (BERT, GPT)

UnsupervisedLanguage modeling, generation

self-supervised pretraining, then supervised fine-tuning

Natural languageGenerative AIComputer vision

Attention lets every token weigh every other token, in parallel, to predict what comes next.

  • Chat assistants
  • Translation and search
  • RAG question answering
More

How it works. Turns each token into a vector and uses attention so every token can weigh how relevant every other token is, all in parallel. Stacking these layers lets the model represent meaning across a whole passage and predict what comes next.

Used for. Chat assistants and code generation (GPT family), search and sentiment analysis (BERT), translation and summarization, retrieval-augmented question answering over company documents, image recognition with vision transformers.

Generative adversarial network

UnsupervisedGeneration

Generative AIComputer vision

A generator forges samples, a discriminator calls them out, and both improve until the fakes pass.

  • Face synthesis
  • Sketch to photo
  • Data augmentation
More

How it works. Two networks train against each other. The generator makes fake samples from random noise; the discriminator learns to tell fakes from real data. Each round the generator gets harder to catch, until its samples look real.

Used for. Photorealistic face and product image synthesis, image-to-image translation (sketch to photo), super-resolution, generating extra training data for rare classes.

Diffusion model (Stable Diffusion, DALL-E)

UnsupervisedGeneration

self-supervised

Generative AIComputer vision

Learns to remove noise step by step, so it can turn pure noise into a new image guided by a prompt.

  • Text-to-image
  • Inpainting
  • Video and audio generation
More

How it works. Learns to undo a process that gradually turns an image into random noise. To generate, it starts from pure noise and removes a little noise at each step, steered by a text prompt, until a new image appears.

Used for. Text-to-image generation, filling in or extending parts of an image, video and audio generation, concept art and product mock-ups.

How they connect.

The bands sort algorithms by how they learn. These five chains show how they descend from one another, which is usually the fastest way to choose between neighbors on the map.

  • Trees grow into ensembles

    →→

    A single tree is easy to read but overfits. A random forest averages hundreds of trees grown on random samples; gradient boosting grows them in sequence, each one correcting the errors of the last. Accuracy rises at each step and interpretability falls.

  • From a line to a network

    →→→

    Logistic regression is linear regression with an S-shaped curve on the output. A neural network stacks many such units in layers. Convolutional networks and transformers are neural networks with structure added for images and sequences.

  • Same distance, different question

    →

    Both measure distance between points, so both need scaled features. K-nearest neighbors uses the labels of nearby points (supervised); K-means has no labels and discovers the groups itself (unsupervised).

  • Attention replaced recurrence

    →→

    Recurrent networks read text one token at a time and struggled with long passages. The transformer reads the whole sequence at once through attention, which made large language models possible and then carried over to images.

  • Two roads to generation

    →

    A GAN learns through a contest between two networks: fast to sample from, hard to train stably. A diffusion model learns to reverse added noise: slower to sample, stable to train, higher quality. Diffusion has largely replaced GANs for image generation since 2022.

Where the lines meet.

Four domains as four lines. Each algorithm is a station; where a station spans several lines, the same algorithm serves several domains. Tabular data runs almost entirely on classical methods; vision, language, and generative AI are served by deep learning, and the transformer is the only station on three lines.

Seventy years, one line.

When each algorithm was introduced. Filled dots are supervised, hollow dots unsupervised. The classical toolkit was complete by about 2001; everything that serves vision, language, and generation at scale arrived after 2012, when deep learning became practical on GPUs.

Transformers, GANs, and diffusion models are marked unsupervised because their training signal comes from the data itself (the next token, the real-or-fake contest, the noise that was added), not from human labels. A supervised fine-tuning stage usually follows for a specific task.

Domain chips show where each algorithm is a standard choice today; most can be pushed into other domains with suitable feature engineering.
